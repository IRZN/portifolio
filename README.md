# Portfólio | Iury Emanuel

Meu portfólio pessoal, feito com HTML, CSS e JavaScript puro, sem frameworks.

🌐 **Acesse:** [https://portifolio-iury-emanuel.vercel.app/]

## Destaques
- Ficha de personagem e árvore de habilidades inspiradas em RPG
- Layout responsivo, que funciona no computador e no celular
- Projetos gerados a partir de uma lista no `script.js`, fácil de atualizar

## Estrutura
- `index.html`: conteúdo da página
- `style.css`: estilos e paleta de cores
- `script.js`: lista de projetos e botão de copiar e-mail
